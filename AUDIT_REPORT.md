# Northwind Kashmir Website Audit

## Scope and implementation model

The project is a static HTML website built with Tailwind CSS. Root pages and
HTML pages under `packages/`, `destinations/`, `hotels/`, `gondola/`,
`trip-stories/`, and `author/` are published as URL-compatible static routes.
Shared navigation and footer markup is injected by
[`scripts/sync-layouts.js`](./scripts/sync-layouts.js). Package and hotel
cluster pages are generated by
[`scripts/generate-cluster-pages.js`](./scripts/generate-cluster-pages.js) and
[`scripts/generate-hotel-pages.js`](./scripts/generate-hotel-pages.js).

## Findings before correction

| Area | Finding | Source of truth |
|---|---|---|
| Business identity | Shared footer contained an unverified GSTIN and used a shortened/inconsistent address and tagline. | `scripts/sync-layouts.js` |
| Business identity | Generated content described the business as government-licensed/tourism-registered and used the supplied reference as a verified licence. The supplied reference must not be presented as independently verified without documents. | `scripts/generate-cluster-pages.js`, `scripts/generate-hotel-pages.js` |
| Marketing claims | Generated safety and service copy used “millions”, “24/7”, “verified” and absolute safety language. | Generator shared text modules |
| Hotel directory | Listings included unverified facilities such as central/heated pools, 24/7 service, and fixed rate claims without occupancy, season, tax, or meal context. | `scripts/generate-hotel-pages.js` |
| Package content | Package copy used fixed inclusions and price ranges without consistently identifying them as indicative or subject to confirmation. | `scripts/generate-cluster-pages.js` |
| Homepage FAQ | FAQ content contained unsupported guarantees and package inclusions, and the source is difficult to maintain as an inline JSON-LD/content block. | `index.html` |
| Gondola | Booking page wording could imply a direct reservation service and did not clearly distinguish the government-operated service from Northwind Kashmir travel assistance. | `gondola/gulmarg-gondola-booking/index.html` |
| Travel information | Homepage and destination content needed an explicit distinction between Srinagar Valley rail connectivity, the Katra–Srinagar corridor, and onward services whose schedules can change. | `index.html`, generated destination copy |
| SEO/build | The site has per-page metadata, canonical URLs, sitemap generation, and JSON-LD, but the build depends on generated output and therefore source templates must be corrected first. | `scripts/`, root HTML |

## Corrections applied

1. Standardize the supplied business name, proprietor, contact details,
   location, tagline, and positioning statement in shared content.
2. Remove the unverified GSTIN and avoid presenting the supplied tourism
   reference as independently verified registration.
3. Replace unsupported numerical, absolute-safety, and 24/7 promises with
   transparent local-planning language.
4. Add explicit indicative-price and availability disclaimers for hotels and
   packages.
5. Clarify that official Gondola tickets are booked through the J&K Cable Car
   Corporation portal, while Northwind Kashmir can provide travel-planning
   assistance only.
6. Add a cautious USBRL/Katra–Srinagar rail connectivity note and avoid
   implying that every Indian train runs directly to Srinagar.
7. Replace the homepage FAQ with sequential, relevant answers that do not
   promise weather, safety, availability, or inclusions.

## Items requiring business-owner or official confirmation

- The supplied tourism registration reference (`JKT-10029-REGD-2022`) should
  only be published as a verified registration after the supporting document is
  checked.
- Hotel facilities, classifications, live rates, taxes, meal plans, and
  availability require confirmation with each property for the traveller's
  dates.
- Package duration, occupancy basis, inclusions, exclusions, cancellation
  terms, and prices require confirmation before being advertised as a quote.
- Current Gondola fares, operating days, maintenance closures, weather
  interruptions, refunds, and the official booking URL must be checked against
  the J&K Cable Car Corporation before each booking.
- Current railway schedules and services must be checked against official
  Indian Railways sources.

## Validation plan

Run `npm run build`, inspect the generated `dist/` tree, and search generated
HTML for removed claims, literal template placeholders, the unverified GSTIN,
and contradictory proprietor names. Validate that canonical URLs, sitemap
entries, and shared navigation remain present.

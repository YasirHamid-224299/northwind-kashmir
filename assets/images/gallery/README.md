# Gallery image folders

Use these folders to manage Gallery images manually:

- `destinations/` - Srinagar, Dal Lake, Gulmarg, Pahalgam, Betaab Valley, Sonmarg, and Tarsar Lake images.
- `adventures/` - Gondola, skiing, trekking, Apharwat Peak, and snow activity images.
- `stays/` - Houseboat, hotel, and snow stay images.

Each image currently has a `.jpg` source and a `.webp` version. The Gallery page uses the `.jpg` paths for compatibility. When replacing an image, keep the same filename and extension, or update its matching `<img>` path in `gallery.html`.

The original files in this folder remain as shared assets for the homepage and other destination pages.
